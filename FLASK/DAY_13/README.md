# 📚 Day 13 – Flask Fundamentals

## 📖 Overview

Today I started learning **Flask**, a lightweight Python web framework used for building web applications and REST APIs. I practiced creating a Flask application, defining routes, returning different types of responses, creating dynamic routes, and handling query parameters.

---

## 🚀 Topics Practiced

* Introduction to Flask
* Importing Flask
* Creating a Flask Application
* Running the Flask Development Server
* Understanding `app.run(debug=True)`
* Creating Routes using `@app.route()`
* Home Route (`/`)
* Returning Plain Text Responses
* Returning HTML Responses
* Returning JSON Responses using `jsonify()`
* Creating Dynamic Routes with URL Parameters
* Handling Query Parameters using `request.args`

## 💻 Programs Implemented

* Created a basic Flask application
* Created a home route that returns plain text
* Returned HTML content from a route

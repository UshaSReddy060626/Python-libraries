# 📅 Day 11 – Python Libraries: OpenCV

## 📖 Overview

Today I started learning **OpenCV**, one of the most popular Python libraries for Computer Vision. I learned the fundamentals of reading, displaying, saving, and modifying images. I also practiced resizing, cropping, drawing shapes and text on images, and converting images between different color formats.

---

## 📚 Topics Covered

### 📖 Introduction
- What is OpenCV?
- Why OpenCV?
- Installing OpenCV
- Importing OpenCV (`cv2`)

### 🖼️ Reading Images
- `cv2.imread()`
- Image Path
- Color Image
- Grayscale Image

### 🖥️ Displaying Images
- `cv2.imshow()`

### ✂️ Cropping Images
- Image Slicing
- Region of Interest (ROI)

### 🎨 Drawing on Images
- `cv2.line()`
- `cv2.rectangle()`

- `cv2.cvtColor()`
- BGR → Gray
- BGR → RGB
